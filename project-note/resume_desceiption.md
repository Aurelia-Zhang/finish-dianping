本地生活服务平台
技术栈：Spring Boot、MyBatis-Plus、Redis、Redisson、RabbitMQ、MySQL、JMeter
项目描述：基于 Spring Boot + Redis 开发的高并发本地生活服务平台，涵盖用户登录、商户查询、优惠券秒杀、点评社交等核心功能。重点针对高并发场景下的数据一致性、超卖等问题进行了深度优化。
1.摒弃传统的 Session 方案，设计并实现基于 Redis + Token 的分布式 Session，解决了集群环境下 Session 共享问题
2.利用 ThreadLocal 配合拦截器实现用户信息的线程内隔离与传递，减少了控制层重复获取用户信息的代码冗余。
3.针对“优惠券秒杀”场景下的超卖问题，利用 Lua 的原子性实现库存预扣减，保证高并发下的数据一致性。
4.引入 Redisson 分布式锁解决一人一单的并发安全问题，并对比了 Synchronized 本地锁在集群模式下的局限性。
5.为了提升用户体验，采用异步解耦策略：主流程仅处理 Redis 交互，通过RabbitMQ异步执行数据库落库操作
6.针对热点 Key 过期瞬间的高并发访问，实现了互斥锁和逻辑过期两种方案，平衡了数据一致性与可用性。 针对查询不存在数据的场景，实现了布隆过滤器方案，保护数据库免受恶意攻击。
